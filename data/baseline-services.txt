# Windows services allowed to connect out while Ask to Connect is on, so that
# Windows keeps working without a prompt (SPEC §7.4). Updated with releases.
#
# One per line: a label, "|", then either
#   service <name>   matched by the service's own SID, whatever program hosts it
#   program <path>   environment variables such as %SystemRoot% are expanded
# Windows' own "Core Networking" rules stay as they are and cover the rest of
# the basics.
